# legacy

Material antigo/exploratório, mantido só como referência histórica. Nada aqui é
usado pelo pacote `vibrometry/` nem pelas figuras do TCC.

| Arquivo | O que é |
|---|---|
| `main.ipynb`, `opa main.ipynb` | Estudos iniciais de visão computacional (filtros, Gabor em imagens, RAW .NEF) e primeira versão do script de figuras. `opa main.ipynb` é pesado (~99 MB, com saídas embutidas). |
| `demo.ipynb` | Demo do pacote `vibrometry` (síntese + vídeo da régua); desatualizado (assume `FPS_OVERRIDE = 30` e um vídeo que não está no repo). Foi escrito para rodar a partir de `Code/vibrometry/`. |
| `EUR_1584.NEF`, `Images/` | Imagens usadas pelos notebooks acima. |

`random.ipynb` (cálculo do IRA) e `interesting.ipynb` (experimentos soltos) foram
removidos; continuam recuperáveis pelo histórico do git.
